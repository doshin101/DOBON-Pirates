# 0008 段階ごとの公開と、URLの変更

決めた日:2026-11-16 / 決めた人:カイさん(方針)、Claude Code(細かい作り)

## 決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| 発信のしかた | 段階(① ミニマム版 → ② ミニマム改良版 → ③ ベーシック版 → ④ ベーシック改良版 → ⑤ UI改良版 → ⑥ 海賊UI版 …)ごとに、別のアドレスで公開する | 過去の投稿を見たときに、その時点のゲームで遊べるようにするため |
| 過去の版の残し方 | **段階ごとにブランチ(コードの枝)を作って残す**。Cloudflare Pages が、ブランチごとに `ブランチ名.プロジェクト名.pages.dev` を自動で作る。そのブランチには、あとから書き足さない | カイさんが選んだ。無料で、Cloudflare の作業がほとんど要らない。段階が増えても、手順が同じ |
| プロジェクト名の変更 | `dobon-pirates` → **`dobon-game`**。Pages のプロジェクト名は変更できないため、新しいプロジェクトを作り直した。今のアドレス(`dobon-pirates.pages.dev`)はやめる | カイさんの希望(発信用のURLにしたい) |
| 最新版のアドレス | https://dobon-game.pages.dev/(`main`) | — |
| ① ミニマム版 | ブランチ `minimum`(2026-11-16、`main` の `c7d0419`(PWAまで入った状態)から作成)。アドレスは https://minimum.dobon-game.pages.dev/ | カイさんの指定 |
| ブランチ名の案 | `minimum-plus` / `basic` / `basic-plus` / `ui-plus` / `pirate-ui`(まだ作らない。作るときに、カイさんが最終決定する) | アドレスの一部になるので、小文字の英数字とハイフンだけ |
| 凍結のルール | 段階のブランチには、push しない・消さない(CLAUDE.md 8節に1行足した)。古い版のバグも直さない | 「当時のゲーム」を残すため |
| 作る順番 | 新しいプロジェクトを作って、`main` のデプロイが成功してから、段階のブランチを作る | プロジェクトを作る**前**にあったブランチは、新しいプロジェクトでは自動でビルドされないため |
| 案内の更新 | README、手順書(`smartphone-workflow.md`、`install-on-phone.md`、`test-seeds.md`)のアドレスを、`dobon-game.pages.dev` に直した | — |
| 古い版のPWA | アドレスが違うと別のアプリになる。今までの `dobon-pirates` のアプリは、引き継がれない(入れ直し) | ブラウザの仕組み |

## ほかの案

- 段階ごとに、Cloudflare のプロジェクトを別に作る(`dobon-minimum.pages.dev` など) → 名前は自由だが、段階が増えるたびに、設定の手間が増えるので見送り
- 自分のドメインを買って、`minimum.〇〇.com` のようにする → 費用と手間がかかるので、いまは見送り。あとから、ドメインを足すこともできる(段階のブランチはそのまま使える)
- Git のタグ(版の印)で残す → Cloudflare Pages は、タグからは公開しないので見送り(ブランチなら自動で公開される)
