# 0006 M4 デバッグと仕上げの作り方

決めた日:2026-11-15 / 決めた人:Claude Code(M4 作業中の小さな判断)

## 決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| デバッグ設定の入り口 | URL(`?debug=1` `?seed=123` `?speed=2`)と、ホームの「設定(デバッグ)」(押すと開く。`?debug=1` のときは最初から開いている) | spec 10節 |
| 「デバッグ表示」の中身 | チェック1つにまとめた:CPUの手札の表、ログを最初から開く、結果画面にシード。**シードと速さは、デバッグ表示がオフでも使える** | 設定の数を減らして、スマホで触りやすくするため |
| シードを決めたときの「もう一度」 | 毎回同じ配りになる(ランダムに戻すには、シードの欄を空にする) | 同じ展開を再現するのが目的のため |
| シードの書き方 | 0 以上 2147483647 以下の整数だけ。それ以外(空・文字・小数・マイナス)はランダムにする | 入力ミスで止まらないように |
| 速さの切り替え | ホームの設定と、対戦中のデバッグ表示(画面の下の ×1 ×2 ×4)の両方 | スマホで、対戦中に速くしたくなるため |
| CPUの手札の表 | 手札(ミニカード)と合計。画面の下に出す | spec 10節。CPUの手札が見えるので、デバッグ表示のときだけ |
| ルール画面 | `docs/rules/minimum.md` の要約を、`ja.json` に書いた(原本は書き換えていない)。6つの見出し(はじめに / 自分の番 / 張る / ドボン / チョンボ / ゲームの終わり)。戻るボタンは「もどる」 | spec 10節「ミニマムルールの要約」。長くなりすぎないよう、箇条書きにした |
| 英語ファイル | `en.json` に、日本語と同じキーを全部入れた。画面の切り替えは作っていない。キーが違うと、型チェックとテストで落ちる(`{名前}` の穴も同じかを確認) | M4 の指示 |
| 画面の文字の検査 | テストで、画面のコード(テスト以外)に日本語や記号(≡ ▲ ▼ ↑ ×)が直接書かれていないかを調べる。記号も `ja.json` に入れた | spec 11節「画面の文字が、言語ファイル経由」を、あとで崩さないため |
| ファイルの読み込み | 上の検査は、Vite の `import.meta.glob` で書いた(`@types/node` などの新しい部品は足していない) | CLAUDE.md 4節 |
| テスト用シードの決め方 | 人間の操作の方針(標準 / 無茶)を `policies.ts` で決めて、3000シードを自動で遊ばせて探した。「ターン数が短い」「手順が分かりやすい」ものを選んだ | 手でも同じ結果になるように、操作を決まりにした |
| 勝つシード・チョンボのシードの条件 | その判定のとき、CPUが宣言していない展開だけ | 人間の操作が少し遅れても、CPUの宣言に先を越されて結果が変わらないようにするため |
| テスト用シードの確認 | 速さ ×1 / ×2 / ×4 の全部で、同じ結果になることを自動テストで確認(12件) | 速さを変えても再現できること |
| 例外メッセージ | `GameRunner` の例外(画面には出ない、開発者向け)は、英語にした | 画面の文字の検査に引っかかるため |

## spec 11節(完成の条件)の確認

| 条件 | 結果 |
|---|---|
| スマホのブラウザで、公開URLを開いて最後まで1ゲーム遊べる | M3 から可能。M4 で、スマホ幅のブラウザで、4つの終わり方を最後まで通して確認した |
| 9-2 の自動テストがすべて通る | T-01〜T-23 すべて通る |
| 4つの終わり方を、画面で確認できる | `docs/mvp/test-seeds.md`(シード 113 / 386 / 26 / 1473) |
| 操作できない理由が、画面に短く出る | プレイ・ドロー・パス・張るに出る(M2・M3) |
| 画面の文字が、言語ファイル経由で出ている | 自動テストで検査(上) |

満たしていなかったもの:なし(直した点は、記号 ≡ ▲ ▼ × と、「×1」などが、コードに直接書かれていたのを `ja.json` に移したこと)。

## ほかの案

- デバッグ表示を、シード・CPUの手札・ログで別々にオンオフする → 設定が増えるので見送り
- ルール画面を、ルール原本(`minimum.md`)をそのまま表示する → 長く、画面の言葉(「張る」「ドボン」など)と少し違うので、要約にした
- 引き分けのシードを、より短いもの(58ターン未満)にする → 3000シードを探したが、見つかった一番短いものが58ターンだった。長いので、速さ ×4 をおすすめしている
