# 0002 M0 の道具選び

決めた日:2026-11-15 / 決めた人:Claude Code(M0 作業中の小さな判断)

## 決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| Node のバージョン | `.nvmrc` は `20` | CLAUDE.md の「20以上」の下限。Cloudflare でも動きやすい |
| React | 18 系 | 安定していて資料が多い |
| テストの動かし方 | ルートの `vitest.config.ts` 1つで全パッケージをまとめて実行 | 設定が1か所で済む |
| パッケージ名 | `@dobon/core`、`@dobon/cpu`、`@dobon/i18n`、`@dobon/web` | 名前の衝突を避ける |
| パッケージの読み込み | `src/index.ts` を直接読む(事前ビルドなし) | ひな形を単純に保てる |
| 文字の取り出し | `getMessages()` で `ja.json` の中身を返す。`en.json` は空の枠 | spec.md 2節(英語ファイルは枠だけ)。言語の切り替えは範囲外 |
| 型チェック | `npm run build` の中で `tsc --noEmit` を先に実行 | 型の間違いがあれば公開前に止まる |

## ほかの案

- パッケージごとにビルドして配る → 今は手間が増えるだけなので見送り
- i18n のライブラリを入れる → CLAUDE.md「なるべく足さない」。MVPは日本語だけなので見送り
