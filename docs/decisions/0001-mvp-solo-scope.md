# 0001 MVPの範囲と作り方

決めた日:2026-11-15 / 決めた人:カイさん(Claudeとの壁打ち)

## 決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| 最初に作るもの | ミニマムルールで、人間1人 vs CPU3人の1ゲーム | ルールの検証と、開発の流れ作りを先にする。対人戦は第2段階 |
| 開発の環境 | **スマホだけ**(Claudeアプリの Claude Code → GitHub → Cloudflare Pages のプレビューで確認) | PCなしで回せるか試したい |
| 技術 | TypeScript + Vite + React + Vitest、npm workspaces | 予定していたフォルダ構成(core と画面を分ける)に合い、テストも書きやすい |
| 制限時間 | ドボン受付の最低時間だけ入れる。自分の手番は時間無制限 | 一人プレイでは急かす必要がない。受付の最低時間がないと、CPUのカードにドボンする暇がない |
| チョンボ | ルールどおり、敗者にする | ミニマムルールの検証のため。カジュアル向けの「受け付けない」仕様は後で検討 |
| ワイヤーフレーム | 仕様書から新しく作る(以前のPowerPointのサンプルは使わない) | — |
| 開始時の初張りの猶予 | 「他に張れる人がいなければ飛ばす」はしない。時間は一定 | 飛ばし方から他の人の手札が読めてしまうため(turn-flow 8節の留意) |

## ほかの案

- 制限時間を仕様どおりすべて入れる / 設定で切り替える → MVPでは見送り
- チョンボを受け付けない / 設定で切り替える → MVPでは見送り
