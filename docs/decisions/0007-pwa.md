# 0007 PWA化(ホーム画面に追加・オフライン対応)

決めた日:2026-11-15 / 決めた人:カイさん(PWA化を選んだ)、細かい作りは Claude Code

## 決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| ねらい | ① ホーム画面に追加できる ② ブラウザの枠なしの全画面で開く ③ 一度開いたあとは、電波がなくても遊べる | ゲームがすべて端末の中で動くので、オフライン対応と相性がよい |
| オフラインの仕組み | 手書きの小さなサービスワーカー(`apps/web/sw/sw.template.js`)。ライブラリ(vite-plugin-pwa など)は足していない | CLAUDE.md 4節「なるべく足さない」。ゲームの範囲では、100行ほどで足りる |
| 保存のしかた | ページ本体(HTML):まずネットワークで最新を取り、つながらなければ保存したものを出す。JS・CSS・画像:保存したものを使う(ファイル名に中身の印が付いているので安全) | 新しい版を公開したとき、次に開いたときに新しくなる。オフラインでも開ける |
| 版の切り替え | ビルドのとき、ファイルの中身から版の印を作る。中身が変わると印も変わり、古い保存が自動で消える。新しい版は待たずにすぐ使う(強制の再読み込みはしない) | 遊んでいる途中で画面が切り替わらないようにするため |
| ビルドへの組み込み | `vite.config.ts` に小さなプラグインを書いて、ビルドのとき `dist/sw.js` を出力する(保存するファイル一覧と版の印を埋める)。埋め忘れたら、ビルドを止める | 保存するファイルの名前は、ビルドのたびに変わるため |
| 登録する場面 | 公開版(本番ビルド)だけ。開発中(`npm run dev`)は登録しない | 開発中に古い保存が残って混乱しないようにするため |
| 新しい開発用の部品 | `@types/node`(型の定義だけ。画面のコードには入らない) | Vite の設定ファイルが Node の機能(ファイル読み込みなど)を使うため、型チェックを通すのに必要 |
| 表示 | `display: standalone`(全画面)、`orientation: portrait`(縦向き)、テーマ色 `#222222`(黒)、背景色 `#ffffff` | spec 10節(スマホの縦持ちが基本) |
| アイコン | ホームのロゴ(枠で囲んだ「DOBON」)を、黒地・白枠・オレンジのアクセントで描いた。192・512(通常)、512(マスク用。中央に収めた)、180(iPhone用)、favicon(SVG)。`apps/web/scripts/make-icons.cjs` で作り直せる | カイさんの指定がなかったので、既存のロゴに合わせた |
| 安全な範囲 | ノッチ・下のバーに隠れないよう、上のバーと下のログに `env(safe-area-inset-*)` の余白を足した。ホーム画面から開いたとき、下に引っぱって再読み込み(ゲームが消える)されないよう `overscroll-behavior: none` | 全画面で開くと、画面の端が隠れることがあるため |
| `_headers` | `sw.js` とマニフェストは `no-cache`、マニフェストの Content-Type を指定 | Cloudflare Pages で、サービスワーカーが古いままにならないように |
| マニフェストの文字 | `name` は「DOBON」(`ja.json` の `app.title` と同じ値)。`description` は日本語を直接書いた | マニフェストは画面のコード(`apps/web/src`)ではなく、画面の文字の検査の対象外。名前を変えるときは、`ja.json` と両方直す |
| 範囲外のまま | 通知、バックグラウンドでの更新、ストアへの公開 | MVPの方針 |

## ほかの案

- `vite-plugin-pwa`(ライブラリ)を使う → 便利だが、部品が増え、ゲームの範囲には大きすぎるので見送り
- 新しい版が出たら、すぐ画面を再読み込みする → 遊んでいる途中で消えるので見送り(次に開いたときに新しくなる)
- 画面の言語に合わせてアプリ名を変える → 言語の切り替えがまだないので見送り
