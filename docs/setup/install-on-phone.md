# スマホのホーム画面に追加する(アプリのように開く)

DOBON は、ホーム画面に追加すると、ブラウザの枠なしの全画面で開けます。**一度開いたあとは、電波がなくても遊べます。**

## 追加のしかた

| 端末 | 手順 |
|---|---|
| Android(Chrome) | 公開URLを開く → 右上の「⋮」メニュー →「ホーム画面に追加」(または「アプリをインストール」)→「追加」 |
| iPhone(Safari) | 公開URLを開く → 下の「共有」ボタン →「ホーム画面に追加」→「追加」 |

> iPhone は、Safari 以外のブラウザ(Chrome など)だと、「ホーム画面に追加」が出ないことがあります。そのときは Safari で開いてください。

ホーム画面に黒地の「DOBON」のアイコンができれば成功です。

## 新しい版になったとき

- 開発で新しい版を公開(PRをマージ)したあと、**電波がある状態でアプリを開く**と、新しい画面になります
- 古い画面のままのときは、アプリを一度閉じて(タスク一覧から消して)、もう一度開いてください
- 電波がないときは、前に開いたときの版で遊べます

## うまくいかないとき

| 症状 | まずやること |
|---|---|
| 「ホーム画面に追加」が出ない | 公開URL(`https://dobon-game.pages.dev/`)で開いているか確認する。プレビューURLでも追加はできるが、PRごとに別のアプリになる |
| オフラインで開けない | 一度、電波がある状態で、公開URLを最後まで読み込む(ホーム画面が出ればOK)。そのあと機内モードで試す |
| 画面の上や下が、ノッチやバーに隠れる | 画面のスクショと機種名を Claude に伝える |
| アイコンを変えたい | Claude に「アイコンを〇〇に変えて」と頼む(`apps/web/scripts/make-icons.cjs` で作っている) |
