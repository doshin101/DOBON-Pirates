# スマホだけで開発する手順

> PCを使わずに「Claudeに指示 → 自動で公開 → スマホで遊んで確認 → 取り込む」を回すための手順です。

## 全体の流れ

```
① Claudeアプリの「Code」タブで指示を出す
        ↓(Claude がクラウドでコードを書き、ブランチを作って PR を出す)
② Cloudflare Pages が PR の「プレビュー版」を自動で公開する
        ↓
③ スマホのブラウザでプレビューURLを開いて遊ぶ
        ↓ 問題があれば、①の同じセッションで直してもらう
④ GitHub で PR をマージ(取り込み)する
        ↓
⑤ Cloudflare Pages が本番の URL を自動で更新する
```

- **PR(プルリクエスト)**:「この変更を取り込んでいいですか?」という申請。中身を確認してから取り込める
- **マージ**:PRの変更を本体(main)に取り込むこと
- **プレビュー版**:PRごとに作られる、試し用の公開ページ。本番には影響しない

## 最初に1回だけやること

### A. GitHub(済み)

- リポジトリ:`doshin101/DOBON-Pirates`(非公開)
- Claude との連携:済み

### B. Cloudflare Pages の設定(スマホのブラウザで。M0 のPRをマージしたあとに行う)

> スマホだと画面が狭いので、ブラウザのメニューから「**PC版サイトを表示**」にすると操作しやすいです。

1. Cloudflare のダッシュボードにログインする
2. 「Workers & Pages」→「作成(Create)」→「Pages」タブ →「Git に接続(Connect to Git)」
3. GitHub を選び、`DOBON-Pirates` へのアクセスを許可する(リポジトリを指定して許可するのがおすすめ)
4. リポジトリ `DOBON-Pirates` を選ぶ
5. ビルドの設定を、次のとおり入れる

| 項目 | 入れる値 |
|---|---|
| 本番のブランチ(Production branch) | `main` |
| フレームワークのプリセット(Framework preset) | `None` |
| ビルドコマンド(Build command) | `npm run build` |
| ビルドの出力先(Build output directory) | `apps/web/dist` |
| ルートディレクトリ(Root directory) | 空欄のまま(`/`) |
| 環境変数(Environment variables) | `NODE_VERSION` = `20` |

6. 「保存してデプロイ(Save and Deploy)」
7. できあがったURL(`〇〇.pages.dev`)をスマホのホーム画面にブックマークしておく

> M0 をマージする前に設定すると、main にはまだゲームのコードがないので、最初のビルドは失敗します。その場合は、マージのあとに「再試行」すれば大丈夫です。設定が済めば、それ以降の PR にはプレビューURLが自動で付きます。

### C. プレビューURLの見つけ方

- PR のページに、Cloudflare からのコメント(またはチェック欄)が付き、そこにプレビューURLが出ます
- 出ないときは、Cloudflare のダッシュボード → プロジェクト →「デプロイ」の一覧から開けます

## 毎回の流れ

1. Claude アプリ →「Code」タブ → 新しいセッション → リポジトリ `DOBON-Pirates` を選ぶ
2. `docs/mvp/tasks.md` の指示文を貼り付けて送る
3. Claude からの質問に答える(分からなければ「おすすめを理由つきで」)
4. 終わったら、PR のプレビューURLをスマホで開いて「確認すること」をチェックする
5. 直してほしいところは、**同じセッション**に書く(スクショも貼れる)
6. OKなら、GitHub(アプリかブラウザ)で PR を開いて「Merge」
7. 数分後、本番のURLに反映される

## 困ったとき

| 症状 | まずやること |
|---|---|
| プレビューURLが出ない・ビルドが失敗した | Cloudflare のビルドログのスクショを Claude に貼って「直して」と頼む |
| 画面が真っ白 | 同じく、症状とURLを Claude に伝える(Claude はクラウドで確認できる) |
| PRがたくさんたまった | 古いものは、Claude に「このPRはもう不要なので閉じて」と頼む |
| どうしてもスマホで無理 | このときだけPCを使う。無理せず、つまずいたこと自体を発信のネタにする |
