# テスト用のシード(4つの終わり方を、画面で再現する)

> 「シード」は、カードの配りと、CPUの選び方の元になる数字です。**同じシードで、同じ操作をすると、いつも同じ展開になります。**
> ここに書いたシードは、自動テスト(`apps/web/src/game/testSeeds.test.ts`)で、毎回確かめています。ルールを変えて結果が変わったら、テストが落ちるので、この文書も直します。

## シードの入れ方(スマホだけでOK)

どちらか1つ。

1. **ホームで入れる**:ホームの下にある「設定(デバッグ)」を押して開く → 「シード」に数字を入れる → 「CPUと対戦」
2. **URLで入れる**:公開URLの後ろに `?seed=113` を付けて開く(例:`https://〇〇.pages.dev/?seed=113`)

あわせて、次の設定が便利です。

| やりたいこと | 方法 |
|---|---|
| CPUの手札・ログ・結果のシードを見る | 「デバッグ表示」にチェック(URLなら `&debug=1`)。対戦中、画面の下に「CPUの手札の表」が出る |
| 速くする | 「進行の速さ」を ×2 / ×4 にする(URLなら `&speed=4`)。対戦中も、画面の下のボタンで変えられる |

> シードを入れたままだと、「もう一度」を押しても、**毎回同じ配り**になります。ランダムに戻すときは、シードの欄を空にします。

## 4つの終わり方

| 終わり方 | シード | 操作の方針 | 何が起きるか |
|---|---|---|---|
| あなたがドボンして勝つ | **113** | 標準 | CPU 3 が出した ♠8 に、あなたが合計8でドボン |
| ドボンされて負ける | **386** | 標準 | あなたが出した ♥Q に、CPU 3 が合計12でドボン |
| チョンボで負ける | **26** | 無茶 | 合計が合わないのにドボンして、チョンボ |
| 引き分け | **1473** | 標準 | 山札がなくなる(58ターンほど。**速さ ×4 がおすすめ**) |

### 操作の方針(「標準」と「無茶」)

この表の操作を、**そのとおりに**してください。1つでも違うことをすると、別の展開になります。

| 場面 | 標準 | 無茶 |
|---|---|---|
| ゲーム開始のカウントダウン中 | 「張る」が押せるなら押す | 同じ |
| 自分の番の最初(まだ何も操作していないとき) | 「張る」が押せるなら押す(予約) | 同じ |
| 出すカード | 出せるカードがあれば、**手札の一番左の出せるカード**を出す。なければドローして、出せるなら一番左の出せるカードを出し、出せなければパス | 同じ |
| 「↑ ドボン」(オレンジ)が出たとき | **自分の合計が、場札の数字と同じときだけ**、上にフリックする | **出たらすぐ**、上にフリックする(合計が違っても) |

- 手札は、左から ダイヤ → ハート → クラブ → スペード の順で、数字が小さい順に並びます
- 「出せないカード」(灰色)や「点線のカード」は選べません。選べるカードの一番左を選びます
- 「↑ ドボン」が出てから、次の人が動くまで、3秒以上あるので、あわてなくて大丈夫です

## 113:あなたがドボンして勝つ

- 配り:あなた = ♥2 ♣5 ♠A(合計 **8**)。親は CPU 3(右)。最初の場札は ♠5
- 手順
  1. カウントダウン中に「**張る**」を押す(合計8なので押せる)
  2. CPU 3 が **♠8** をプレイする → 場札の周りにオレンジの枠(ドボン受付中)が出て、メインボタンが「**↑ ドボン**」になる
  3. ボタンを**上にフリック**する(合計8 = ♠8 の数字8)
  4. 「判定待ち…」→ 画面中央に「**ドボン!** あなた の勝ち」→ 結果画面(あなたが勝者、CPU 3 が敗者)

## 386:ドボンされて負ける

- 配り:あなた = ♦2 ♥Q ♠A(合計15)。**あなたが親**。最初の場札は ♥A。CPU 3(右)は合計12で、開始時に張る
- 手順
  1. あなたの合計は15なので、「張る」は押せない(何もしない)
  2. あなたの番になったら、出せるカードは ♥Q と ♠A。**一番左の出せるカード = ♥Q** を選んで「プレイ」
  3. CPU 3 が、合計12 = ♥Q の数字12 で、ドボンする
  4. 「**ドボン!** CPU 3(右) の勝ち」→ 結果画面(あなたが敗者、CPU 3 が勝者)

## 26:チョンボで負ける

- 配り:あなた = ♥4 ♠8 ♥A(合計 **13**)。親は CPU 3(右)。最初の場札は ♠6
- 手順(**無茶**の方針)
  1. カウントダウン中に「**張る**」を押す(合計13は、張れる)
  2. CPU 3 が **♠Q**(数字12)をプレイする → メインボタンが「**↑ ドボン**」になる
  3. あなたの合計は13で、♠Q の12と**合っていない**けれど、そのまま**上にフリック**する
  4. 「判定待ち…」→ 画面中央に「**チョンボ!** あなた の負け」→ 結果画面(あなたが敗者。勝者はなし)

## 1473:引き分け

- 配り:あなた = ♠7 ♣8 ♠K(合計28)。**あなたが親**。最初の場札は ♣J
- 手順:上の「標準」の方針で、最後まで遊ぶ。途中の目印:
  - 最初に、あなたは **♣8** をプレイする(出せるのは ♣8 だけ)
  - 次に CPU 1(左)が ♣10、CPU 2(上)が ♣5 をプレイする
  - あなたの合計が13以下になったら、自分の番の最初に「張る」を押す。**ドボンのボタンは、合計が場札と同じときだけフリックする**(この展開では、チョンボしないよう、合っていなければ何もしない)
- 山札が0枚になり、ドローが必要な人が出たところで、「**引き分け**」(「山札がなくなりました」)

## うまく再現できないとき

- ログ(画面の下の「ログ」)と、上の説明を見比べて、どこから違うか確認する。「あなた が張った」「CPU 3(右) が ♠8 をプレイ」などが、同じ順に出れば合っています
- 「デバッグ表示」をオンにすると、CPUの手札も見えて、違いに気づきやすいです
- それでも違うときは、シードと、違った場面を Claude に伝えてください

## シードの探し方(Claude 用)

`npx vite-node apps/web/scripts/find-test-seeds.ts` で、4つの終わり方になるシードを探せる(「標準」「無茶」の方針は `apps/web/src/game/policies.ts`)。`npx vite-node apps/web/scripts/explain-seed.ts standard 113` で、そのシードの展開を文章で書き出せる。
