# ドボン ルール仕様書:ミニマムルール v0.17

最終更新:2026-11-10

> **このファイルは、Claudeプロジェクト「ドボン開発プロジェクト」の `docs/rules/minimum.md`(v0.17)の写しです。** 変更履歴は原本にあります。ルールを変えるときは、カイさんが原本を直してから、このファイルを差し替えます。Claude Code はこのファイルを勝手に書き換えないでください。
>
> この写しから参照されている `docs/rules/basic.md`・`docs/rules/advance.md`・`docs/design/turn-flow.md`・`docs/design/ui-effects.md` は、このリポジトリにはありません。MVPに必要な部分は `docs/mvp/spec.md` にまとめてあります。

> **ミニマムルール**は、ドボンを成り立たせるために本当に必要なものだけを集めた、最小限の1ゲームです。
> ポイントも保有ポイントも倍率もありません。ドボンが決まった時点で、そのゲームが終わります。
> ここに入らなかったプレーンルールの項目は、ベーシックルール(`docs/rules/basic.md`)とアドバンスルール(`docs/rules/advance.md`)に移しています。ルールは、ミニマム・ベーシック・アドバンス・エクストラの4つの層に分かれていて、ミニマムはその1層目です。
> 用語は用語集(`docs/rules/glossary.md`)に従います。画面の状態・制限時間などの仕様はターン進行の仕様(`docs/design/turn-flow.md`)にあります。

## M-1. 準備

| 項目 | 内容 |
|---|---|
| 人数 | 4人 |
| カード | トランプ52枚(ジョーカーなし) |
| 最初の手札 | 各3枚 |
| 最初の場札 | 山札の一番上を1枚めくり、捨て札の最初の1枚にする(これを**最初の場札**と呼ぶ) |
| 親 | ランダムで決める。**親から最初のターンを行う** |
| ターンの順 | **時計回り** |
| ゲームの長さ | **1ゲーム勝負**(保有ポイント・複数ゲームなし) |

### 場札とは

- **捨て札の一番上の1枚を場札と呼ぶ**。最初の場札も場札の一種である。以後の条文の「場札」はすべてこの1枚を指す

### カードの数字

| カード | 数字 |
|---|---|
| A | 1 |
| 2〜10 | そのまま |
| J / Q / K | 11 / 12 / 13 |

## M-2. ターンの流れ

### 操作

| 操作 | 内容 |
|---|---|
| プレイ | 手札から、場札に合うカードを1枚出す |
| ドロー | 山札から1枚引く |
| パス | 何もせずに終える(ドローの後だけ) |

- 操作を**実行する**とは、プレイ・ドロー・パスを実際に行うこと。**カードを選んだだけでは、まだ実行ではない**
- **操作完了**は、プレイまたはパス。ドローだけでは操作完了にならない

### 操作の選択肢

| 場面 | できる操作 |
|---|---|
| ターンの開始時 | **プレイ** または **ドロー** |
| ドローの後 | **プレイ** または **パス** |

- パスは、ドローの後にしかできない(ターンの開始時にいきなりパスはできない)
- ミニマムでは「プレイできるなら必ずプレイ」なので、実際の選択は次のとおり
  - ターンの開始時に、手札が2枚以上で、プレイできるカードがある → **プレイ**(ドローは選べない)。場札と**同じ数字か同じマーク**のカードが、プレイできるカード
  - ターンの開始時に、手札が2枚以上で、プレイできるカードがない → **ドロー**。ドローの後、プレイできるカードがあれば**必ずプレイ**、なければ**パス**
  - 手札が1枚のとき → **ドロー**(プレイは選べない)。ドローの後は、上と同じ
- プレイできるカードが複数あるときは、どれをプレイしてもよい
- カードに特別な効果はない

### 手札が1枚のとき

**ドボン以外の上がり禁止。手札が1枚のときは先にドローする。**

- 手札をなくして上がることはできない(勝つ方法はドボンだけ)
- 手札が1枚のときは、ターンではまず山札から1枚ドローし、2枚になってから、プレイできるカードがあれば必ず1枚プレイする(2枚のどちらをプレイしてもよい)
- プレイできるカードがなければパス(手札は2枚のまま)

### ターンの進み方

1. **ターンの開始**:手番のプレイヤーが示される
2. **操作**:手番のプレイヤーが操作し、操作完了(プレイまたはパス)で終える
3. **操作完了の直後**:手番のプレイヤーは張れる。カードがプレイされたときは、ドボンの受付が始まる(M-4)
4. **ターンの終了**:操作完了の直後の時間が終わると、ターンが終わり、次のプレイヤーのターンが始まる

- ドボンの受付は、ターンの終わりをまたいで、次のプレイヤーが最初の操作を実行するまで続く(M-4)
- 手番のプレイヤー以外は、操作できない(ドボンの宣言と、ゲーム開始時の張る宣言を除く)
- 時間制限がある場合の扱いは、ルールではなく仕様とする。時間切れのときは、ルールで決まっている操作が自動で行われる

## M-3. 張り

| 項目 | 内容 |
|---|---|
| 条件 | 手札の合計が**13以下** |
| 張る宣言 | 自分で操作して張る(自動では張られない。例外は、アドバンス S-14 のオールドボンで再開するときだけで、全員が自動で張り状態になる) |
| 宣言できるとき | 次の2つのときだけ(下記)。それ以外のときは宣言できない |
| 張りの確定 | **操作完了の時点の手札の合計**が13以下なら張りが確定し、14以上なら失敗する。操作の途中の合計は見ない |
| 張らないとどうなるか | **張っていないとドボンできない**。張っていないプレイヤーはドボンの操作自体ができない(仕様として操作を受け付けない) |
| 公開 | **誰が張っているかは全員に公開される** |
| 張った後 | カードのプレイもドローもできる |
| 解除 | **操作完了の時点の手札の合計**が14以上なら、**自動で解除**される(張ったままは不可)。操作の途中で14以上になっても、操作完了の時点で13以下なら解除されない |
| 自分からの解除 | **できない**。解除は自動解除のみ |
| 解除のあと | 次のターン以降に合計が13以下に戻っても、自動では張り直されない。**張り直す宣言が必要** |

### 宣言できるとき

張る宣言ができるのは、次の2つのときだけ。

1. **ゲーム開始時**:最初の手札が配られてから、**最初のターンが始まるまで**(全員が張れる。時間や猶予の扱いは、仕様として別に決める。ターン進行の仕様(`docs/design/turn-flow.md`)の「8. ゲーム開始時」)
2. **自分のターン**:ターンの開始から、ターンの終了まで(操作完了の直後を含む)

- 操作の前に宣言した場合は、確定が操作完了の時点まで保留される(その時点の合計が13以下なら確定、14以上なら失敗)。操作完了の直後に宣言した場合は、その時点の合計で決まる
- ゲーム開始時の張りは、操作がないので、**押した時点の合計**で確定する
- ミニマムでは、ゲーム開始時に張ることは最初の場札へのドボンのためではない(最初の場札はドボンの対象外、M-4)。親が最初にプレイするカードに備えるための宣言である。アドバンス S-14(初ドボン)がオンのときは、最初の場札へのドボンにも使える
- ドボンしたい場札がプレイされる**前に**、張りが確定していなければならない。場札がプレイされた後に張っても、その場札にはドボンできない

### 継続について

- 「継続」は、張った状態で自分のターンが回ってきて、ターンの終了時にも張りが続いている状態。**張りが続いていることを示すだけの状態**であり、それ自体がルール上の効果を持つことはない。成否に影響するのは「張っているかどうか」だけである
- 継続の定義は用語集(`docs/rules/glossary.md`)に従う

- 張りの宣言やボタンの見せ方、張っている人の見え方、継続のテロップは**演出**として扱う(`docs/design/ui-effects.md`)。「張っているかどうかが全員に見える」こと自体はルール。

## M-4. ドボン

- **ドボンはプレイヤーが操作して宣言するものとする。条件がそろっても、自動では成立しない**

| 項目 | 内容 |
|---|---|
| 条件 | 張っていて、**場札の数字 = 自分の手札の合計** |
| 対象 | 場札のみ。ただし**最初の場札は対象外** |
| 自分のカード | 自分がプレイした場札にはドボンできない。ボタン仕様として、**操作を受け付けない** |
| 最初の場札 | 誰もプレイしていないので対象外。ボタン仕様として、**操作を受け付けない**(アドバンス S-14 の初ドボンがオンのときを除く) |
| ドボン受付 | カードがプレイされて操作が完了した直後から、**次のプレイヤーが最初の操作を実行するまで**。カードを選んだだけでは、受付は終わらない。長さそのものはルールに書かない(ゲームの仕様として別に決める) |
| 受付と張りの宣言 | **張りの宣言では受付は終わらない** |
| 判定のタイミング | ドボンとチョンボの成否は、**受付が終わる時点でまとめて判定する**。ドボンまたはチョンボの宣言があったときは、宣言から**短い猶予**のあとに受付を終わらせて判定する(猶予の長さは仕様)。猶予の間に宣言された分も、同じ判定に含める。受付の途中で確定はしない |
| 猶予の間 | 次のプレイヤーの操作の実行は、判定が済むまで保留される |
| 同時に複数人がドボンできる場合 | プレイした人から**時計回りで次のターンに近い人**が優先(勝者は1人だけ) |
| ドボンとチョンボが重なった場合 | **ドボンが優先**される(M-5) |

- 受付は場札1枚につき**1回だけ**。カードがプレイされなかった(パスだった)ときは、場札が変わらないので、受付はない。パスで場札が残っても、受付は**再開しない**
- ドローして手札の合計が場札と一致しても、**ドボンはできない**(引きドボンはミニマムルールにはない)

### ドボンの操作の扱い

| 状態 | 扱い |
|---|---|
| 張っていない | ドボンの操作を**受け付けない** |
| 最初の場札、または自分がプレイしたカード | ドボンの操作を**受け付けない**(ボタン仕様。初ドボン S-14 がオンのときの最初の場札を除く) |
| 張っているが、受付の時間外 | 操作はできるが**無効**(ノーカウント。チョンボにはならない) |
| 張っていて、受付中で、合計が場札の数字と一致していない | **チョンボ**(M-5) |
| 張っていて、受付中で、他の人がプレイした場札に合計が一致している | **ドボン**(複数なら上の優先順位で1人) |

- 受付中に張りが確定するのは、カードをプレイした本人だけである。次のプレイヤーは自分のターンの①②で張る宣言ができるが、確定は操作完了の時点なので、受付が閉じる(最初の操作の実行)までには確定しない。そのため、他の人のカードにドボンできるのは、**カードがプレイされた時点で張っているプレイヤー**に限られる

### 勝者と敗者

| 立場 | 結果 |
|---|---|
| ドボンした人 | **勝者** |
| そのカードをプレイした人 | **敗者** |
| 残りの2人 | 勝者でも敗者でもない(**順位はつけない**) |

- ドボンが成立した時点でゲームは終了する。

## M-5. チョンボ

場札の数字と手札の合計が**一致していないのに**ドボンしたら**チョンボ**。判定は受付が終わる時点で行う(M-4)。

| 項目 | 内容 |
|---|---|
| 結果 | チョンボした人は**敗者**になる。そのゲームは終了する |
| 複数のチョンボ | 有効なドボンがなく、チョンボが複数あった場合は、**チョンボした全員が敗者**になる |
| 全員のチョンボ | **引き分け**とする(勝者・敗者なし)。通常のドボン受付ではボタン仕様のためチョンボは最大3人までだが、初ドボン(`docs/rules/advance.md` の S-14)の受付では全員がチョンボし得る |
| 他の人 | 勝者でも敗者でもない(順位はつけない)。ただし複数のチョンボに含まれる人は敗者になる |
| ドボンと重なった場合 | 同じドボン受付の中でチョンボとドボンが重なったら、**押した順にかかわらずドボンを優先**する(チョンボは取らない) |

- 張っていない人はそもそもドボンを操作できないので、チョンボになるのは「張っている人が受付の中で誤ってドボンした」場合だけ。
- 受付の時間外のドボン操作は**無効(ノーカウント)**で、チョンボにはならない。
- 理論上は、最初の場札へのドボンと、自分がプレイしたカードへのドボンも「誤ったドボン」だが、どちらもボタン仕様として操作を受け付けないため、チョンボとしては発生しない(M-4)。最初の場札は、アドバンス S-14 の初ドボンがオンのときだけ受け付ける。

---

## M-6. 山札がなくなったら

- 山札がなくなり、ドローする必要があるのにドローできなくなった時点で**引き分け**
- ただし、**ドボン・チョンボの判定を先に行い**、成立しなければ引き分けとする(判定は、次のプレイヤーの最初の操作の実行より前に済んでいる)
- 引き分けでは、勝者も敗者もいない(順位もつけない)
- 例:手札が1枚のプレイヤーのターンで山札が尽きている場合は、その1枚が**プレイできるカードでも引き分け**になる(手札1枚のときは先にドローしなければならないため)

---

## M-7. ゲームの終わり

ゲームは次のどれかで終わる。

| 終わり方 | 結果 |
|---|---|
| ドボンが成立した | ドボンした人が勝者、プレイした人が敗者(M-4) |
| チョンボが起きた | チョンボした人が敗者。複数の場合は全員が敗者(M-5) |
| 全員がチョンボした | 引き分け(初ドボン S-14 の受付でのみ起こり得る。M-5) |
| 山札がなくなった | 引き分け(M-6) |

- ベーシック以上のルールを使うときは、終わり方が増えることがある(バースト:`docs/rules/basic.md` の S-12)。

## M-8. 見える情報

| 情報 | 見えるか |
|---|---|
| 自分の手札 | 見える(見せ方は演出) |
| 全員の**手札の枚数** | **見える** |
| **誰が張っているか** | **見える**(M-3) |
| 場札(捨て札の一番上) | **見える** |
| **場札がプレイされたカードか、最初の場札か**(プレイされたカードなら、プレイした人) | **見える** |
| **現在のターンのプレイヤー**と、**ドボン受付中かどうか** | **見える** |
| 山札の残り枚数 | **見える** |
| 他の人の手札の中身 | 見えない |
| 捨て札の中身(場札以外) | 見えない |
