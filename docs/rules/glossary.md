# ドボン 用語集(MVP用の抜粋)

> **このファイルは、Claudeプロジェクト「ドボン開発プロジェクト」の `docs/rules/glossary.md`(v0.15)から、ミニマムルールのMVPで使う言葉だけを抜き出したものです。** 原本にはベーシック・アドバンス・オンライン対戦の言葉もあります。
>
> - 画面に出す日本語は、この表の「日本語」に合わせる
> - **コード上の名前(変数・型・関数)は「コードでの名前」の列に合わせる**(英語の列を元に、Claudeが提案したもの)
> - 表にない言葉が必要になったら、勝手に作らずに、カイさんに確認する

## 進行の単位

| 日本語 | English | コードでの名前 | 定義 |
|---|---|---|---|
| 対戦 | Match | `match` | 勝負の単位。ミニマムは1ゲームのみ |
| ゲーム | Game | `game` | 開始から、ドボン・チョンボ・引き分けのいずれかで終わるサイクル |
| ターン | Turn | `turn` | 手番のプレイヤーが操作する単位。①ターン開始 ②操作待機 ③操作中 ④受付中 ⑤ターン終了 |

## 人

| 日本語 | English | コードでの名前 | 定義 |
|---|---|---|---|
| プレイヤー | Player | `player` | ゲームに参加する人(CPUを含む) |
| 親 | Starting Player | `startingPlayer` | 最初にターンが来る人 |
| 手番のプレイヤー | Current player | `currentPlayer` | 今ターンを行っている人 |
| 勝者 | Winner | `winner` | ドボンした人 |
| 敗者 | Loser | `loser` | ドボンされた人(カードをプレイした人)と、チョンボした人 |
| CPU | CPU player | `cpu` | 人間以外のプレイヤー |

## カード

| 日本語 | English | コードでの名前 | 定義 |
|---|---|---|---|
| 山札 | Stock | `stock` | まだドローされていないカードの山 |
| 手札 | Hand | `hand` | プレイヤーが持っているカード |
| 捨て札 | Discard | `discard` | 最初の場札と、プレイされたカード全体 |
| 場札 | Top card | `topCard` | 捨て札の一番上のカード |
| 最初の場札 | Starting top card | `isStartingTopCard` | ゲーム開始時に山札からめくった場札。ドボンの対象外 |
| 数字 | Rank | `rank` | A=1、2〜10、J=11、Q=12、K=13 |
| マーク | Suit | `suit` | スペード・ハート・ダイヤ・クラブ(`S` `H` `D` `C`) |
| 合計 | Total | `handTotal` | 手札の数字を足したもの |

## 動作・状態

| 日本語 | English | コードでの名前 | 定義 |
|---|---|---|---|
| プレイ | Play | `play` | 手札から場札に合うカードを出すこと |
| ドロー | Draw | `draw` | 山札から1枚引くこと |
| パス | Pass | `pass` | ドローの後に、プレイせずに操作を終えること |
| 操作 | Action | `action` | プレイ・ドロー・パスのいずれか。カードを選んだだけでは操作の実行ではない |
| 操作の実行 | Execute | `execute` | 操作を実際に行うこと |
| 操作完了 | Action complete | `actionComplete` | プレイまたはパス。ドローだけでは操作完了にならない |
| 張り(張る) | Armed(Arm) | `armed` / `arm` | 手札の合計が13以下で、ドボンできる状態にすること |
| 仮押し | Provisional arm | `provisionalArm` | 操作完了の前に張りボタンを押すこと。操作完了時の合計が13以下なら確定、14以上なら失敗 |
| 解除 | Disarm | `disarm` | 操作完了の時点で手札の合計が14以上になって、張りが自動で外れること |
| 継続 | Still Armed | `stillArmed` | 張った状態で自分のターンが回ってきて、ターンの終了時にも張りが続いている状態。ルール上の効果はない |
| 初張り | First Arm | `firstArm` | ゲーム開始時に、最初の手札が配られた直後に張ること |
| ドボン | Dobon | `dobon` | 張っていて、他のプレイヤーがプレイした場札の数字が手札の合計と同じときに宣言すること |
| ドボン受付 | Dobon window | `dobonWindow` | カードがプレイされて操作が完了した直後から、次のプレイヤーが最初の操作を実行するまでの、ドボンできる時間(④⑤①②) |
| 猶予 | Grace period | `gracePeriod` | ドボンまたはチョンボの宣言から判定までの短い時間 |
| 無効 | Void | `void` | 受付の時間外のドボン操作が、なかったことになること |
| 判定 | Resolution | `resolution` | 受付の終了時に、ドボンとチョンボの成否をまとめて決めること |
| チョンボ | Foul | `foul` | 張っている人が受付中に、合計が一致していないのにドボンすること |
| 引き分け | No Contest | `noContest` | 勝者も敗者もいないままゲームが終わること |

## 使わない言葉(MVPの範囲外)

ポイント、保有ポイント、精算、倍率、まとめ出し、バースト、自発的パス、ジョーカー、引きドボン、ドボン返し、ダブルドボン、初ドボン、オールドボン、ルーム、ホスト、観戦者
